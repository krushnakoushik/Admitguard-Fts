**Built by:** Koushik  
**Cohort:** 2025  
**Project Type:** Vibe Coding — Google AI Studio

## Overview

AdmitGuard is a client-side web application that validates candidate admission 
data in real-time, enforces eligibility rules at the point of entry, and 
maintains a full audit trail of every submission.

Built to solve a real operational problem in the FTS admission pipeline.
