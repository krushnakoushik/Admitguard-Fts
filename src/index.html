System Help & Reference

Operator Quick Guide

AdmitGuard is designed to ensure 100% data compliance for candidate admissions. Follow these steps to process a record:

1. Data Entry

Fill in all 11 required fields. The system validates each field as you type. Green borders indicate a "Clean" pass.

2. Handling Exceptions

Amber borders indicate a "Soft Rule" violation (e.g., candidate is slightly over age). You can override these by toggling the "Rule Exception" switch and providing a valid rationale containing required keywords.

3. Strict Blocks

Red borders indicate a "Strict Rule" violation (e.g., invalid Aadhaar format). These cannot be overridden. The submit button will remain disabled until fixed.

4. Manager Flags

If a submission uses more than 2 exceptions, it is automatically "Flagged" for manager review. Flagged records appear in amber in the audit log.
